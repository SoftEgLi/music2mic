2026-09-12：CS2 转盘选歌后没有按住 C 的实机诊断与修复
一、确认的根因
1) 本机 Steam CS2，本地 de_dust2 地图，无在线队友；运行时 bind c 为 +voicerecord，
   语音输入为 CABLE Output，配置正确。
2) 旧版转盘可见时 GetForegroundWindow 仍属于 CS2（本次 PID 11040），
   GetClipCursor 为 (960,540,961,541)，即鼠标被锁在屏幕中心的一个像素。
   尝试移动到歌曲位置 (960,385) 后，实际位置仍是 (960,540)。点击命中中央停止，
   数字键也未交给转盘，播放/PTT 流程根本没有执行。
3) 直接在 CS2 前台发送 C 做对照：原虚拟键方式和扫描码方式都能亮起语音标识。
   因此“CS2 不接受虚拟键”不是本机这次故障的根因；仅做桌面按键测试不足以确诊。
4) 另修复选歌隐藏转盘后未恢复原窗口焦点的问题，避免把 C 发给播放器窗口。
二、修复
- wheel.py：打开转盘时激活原生顶层窗口；必要时临时 AttachThreadInput 后重试，
  finally 中解除关联。激活失败时关闭转盘并提示，避免显示无法操作的菜单。
  选歌时先恢复游戏前台再隐藏；确认恢复后播放，最多等待 0.5 秒，超时取消。
- ptt.py：通过完整 Windows INPUT 结构发送扫描码并检查 SendInput 返回值；
  发送失败明确返回错误，停止时释放实际按下的键，失败保留状态供重试。
  ptt.log 仅记录本程序自己的 PTT 发送及其前台进程。
- gui.py：每次选歌先释放旧 PTT 再按下新 PTT，包含重复选择同一首歌；
  按键发送失败显示具体原因，不再无条件报告按住成功。
